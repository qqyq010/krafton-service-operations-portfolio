# 조건을 바꾸면 이전 계산 결과를 지우는 처리

입력 조건과 다른 결과가 남아 있으면 비교를 잘못할 수 있습니다. 현재 코드는 조건을 바꾸면 결과를 지우고, 뒤늦게 도착한 이전 요청의 응답도 사용하지 않도록 처리합니다. 계산 자료가 바뀌었는지도 checksum으로 대조합니다.

이 구현과 자동 검사는 AI가 수행했습니다. 검사 기록에는 전투 길이를 바꾼 뒤 결과를 지우고 다시 계산하는 경우, 지원하지 않는 파티로 바꿨을 때 이전 결과를 다시 쓰지 않는 경우가 남아 있습니다.
