# 차선호 서비스운영 포트폴리오

게임을 직접 플레이하며 불편을 찾고 수정 결과를 확인했습니다. Coin Survivor의 상점과 인벤토리 개발에 참여했고, AI를 활용한 문서 정리와 개인 도구 제작도 진행했습니다.

| 사례 | 제가 한 일 |
