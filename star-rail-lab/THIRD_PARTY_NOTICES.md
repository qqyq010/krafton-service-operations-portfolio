# 외부 구성품

실제 UI는 React(MIT), Phosphor Icons(MIT), Noto Sans KR(SIL OFL1.1)를 사용합니다. 설치된 패키지의 라이선스 파일에서 확인했습니다. 이 묶음에는 해당 패키지 소스나 폰트 파일을 재배포하지 않고 앱의 렌더링 화면을 포함합니다.

게임 명칭·캐릭터·광추 이름과 고정 DB 수치의 원 권리는 해당 권리자에게 있습니다. 공식 서비스·공식 검증 도구·제휴 제품을 의미하지 않습니다. 원본 DB와 게임 이미지 자산은 제외했습니다.

선별 코드는 프로젝트 작업본의 발췌이며 전체 앱 라이선스 부여나 원 데이터 공개 허가를 대신하지 않습니다.
