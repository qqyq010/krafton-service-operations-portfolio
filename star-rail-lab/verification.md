# 실행 확인과 남은 범위

기준일은 2026년 10월 20일입니다. 아래 내용은 원 프로젝트에서 남긴 실제 앱 실행과 검사 기록을 옮긴 것입니다.
이 포트폴리오 저장소는 선별 코드와 문서의 모음이므로 해당 검사 전체를 이 저장소에서 재실행할 수는 없습니다.

## 확인한 흐름

| 항목 | 기록된 결과 |
| --- | --- |
| 캐릭터와 광추 A와 B 비교 | 실제 로컬 API로 계산한 수치와 입력 목표 표시 |
| 입력 변경 | 이전 계산 결과 제거 |
| 비교 탭 이동 | 같은 비교의 입력과 결과 유지 |
| 동일 인물의 파티 중복 | 거부 |
| 파티 관계 | 지정한 파티원 변경에 따른 연결 차이 표시 |
| 조건별 효과 | 직접 지정한 발동 조건의 수치 계산 |
| 1920 픽셀 화면 | 가로 넘침 없음 확인 |
| 2560 x 1440 화면 | 실제 앱 캡처 5장 |

[항목별 실행 결과](evidence/verification.json)

## 관련 검사 기록

- UI 회귀 112개 통과
- 후속 효과 UI 37개 통과. 112개와 겹치는 재검사이므로 합산하지 않음
- 비교 API 84개 통과
- 프론트엔드 빌드 통과. 기존 큰 번들 경고는 유지

캡처는 실제 HTTP 요청과 기존 계산 코드를 거쳤습니다. 사용한 입력은 인공적으로 지정한 가정이며 실제 계정 자료는 사용하지 않았습니다.
앱 시작 확인은 기존 격리 서버 연결 기준입니다. 새 환경에서 시작 스크립트를 처음 실행하는 흐름까지 확인한 기록은 아닙니다.

## 데이터 기준

고정 후보 DB 4.6.0입니다. [DB와 엔진의 근거 지문](evidence/source-pins.json)을 보존했습니다.
이 버전 표기는 캡처 때 읽은 자료를 뜻하며 현재 게임의 최신성과 모든 규칙 지원을 검증한 의미는 아닙니다.

## 추가 검증이 남은 부분

- 실제 계정 전체 스캔과 정답 대조
- 현재 보유 장비를 반영한 최적 배분과 추천
- 전체 캐릭터 규칙과 전투 수명, 자동 행동 순서
- 실제 피해량과 게임 내 성능의 일치
- 일부 긴 이름과 작은 화면의 표시 밀도

기존 Scanner 문제는 별도 미완료 상태입니다. 이번 비교 화면과 API 실행 결과로 Scanner나 전체 시뮬레이션이 완성됐다고 표현하지 않습니다.
