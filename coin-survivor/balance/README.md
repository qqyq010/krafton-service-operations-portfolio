# 밸런스 시트

[Excel 열기](coin-survivor-balance.xlsx)

구매·확장 비용과 성장 흐름을 비교한 계산표입니다. 2026년 7월 16일 코드·데이터를 기준으로 만들었고 전투 수치와 플레이 측정 양식도 함께 넣었습니다.

비용을 검토한 계기는 첫 상점에서의 선택이었습니다. 114골드로 상품 네 개를 사면 74골드가 남는데 첫 가방 확장에는 100골드가 필요했습니다. [구매·확장 사례](../cases/shop-and-bag-costs.md)에서 이 상황과 조정 방향을 볼 수 있습니다.

## 12개 시트 구성

| 시트 | 들어 있는 내용 |
|---|---|
| 대시보드 | 구매·확장 문제와 조정 목표 |
| 현재 기준 | 2026년 7월 16일 기준값과 출처 |
| 성장 곡선 | 누적 획득 목표와 상점 진입비·잔액 계산 |
| 스폰 타임라인 | 시간별 적 유지 목표와 근거리·원거리 구성 |
| 적·보스 | 체력·피해·보상·출현 시각 |
| 경제 흐름 | 구간별 성장 목표와 상점 이용 후 남는 골드 |
| 인벤토리 경제 | 확장비·합성 원가·판매 회수율·점유 칸 |
| 패시브 시너지 | 등급별 효과와 발동 조건 및 조합별 확인 항목 |
| 무기 DPS | 무기 비교 계산과 실제 피해량 입력란 |
| 성장·카메라 예산 | 몸집·카메라 배율과 상점 전후 상태 |
| 플레이 모드 입력 | 시간별 측정값과 구간 판정·수정 후 테스트 양식 |
| 데이터 품질 | 출처와 확인 방법 |

## 계산값과 측정값

노란 칸은 실제 플레이 값을 넣는 곳이며 현재는 비어 있습니다. ‘플레이 모드 입력’은 필요한 숫자 6개가 들어와야 구간을 판정합니다. 계산표의 수치와 실제 측정 결과를 구별해서 읽으면 됩니다.

공격 범위와 분열을 코드에서 조정한 작업은 [진화 무기 사례](../cases/evolved-weapon-balance.md)에 있습니다.
