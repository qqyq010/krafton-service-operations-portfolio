# AI를 활용한 회의록과 작업 기록 정리

AI로 회의 영상을 전사하고 작업 기록을 정리했습니다. 저는 회의록에 빠진 내용을 보완해 팀과 공유하고, 작업 기록의 누락과 복잡한 파일 이름을 고치도록 요청했습니다.

## 회의 영상을 전사하고 팀과 공유

Coin Survivor의 회의 영상을 faster-whisper로 전사해 회의록 초안을 만들었습니다. 전사본에 없는 제 안건은 따로 적어 둔 메모를 보고 추가했습니다.

4월 27일 회의에서는 인벤토리 조작을 드래그해서 놓는 방식에서 아이템을 집어 든 뒤 놓는 방식으로 바꾸기로 했습니다. 이 안건을 회의록에 추가해 팀과 공유하고 다음 작업을 정하는 데 사용했습니다.

> 차선호: Inventory 조작 방식을 drag & drop에서 pick up & drop 방식으로 교체하는 작업을 진행한다.

## Obsidian에서 완료한 일과 남은 일 확인

Coin Survivor와 Fisher의 작업 로그와 할 일 목록을 AI로 정리했습니다. 저는 Obsidian에서 읽으며 어떤 일을 했고 이전에는 무슨 문제가 있었는지 확인했습니다.

기록에 빠진 내용은 보완하도록 요청했습니다. 폴더와 파일 이름이 길고 난해할 때는 짧고 알아보기 쉽게 바꾸도록 했습니다.

| 실제 기록에 남은 내용 | 읽으며 확인한 것 |
| --- | --- |
| Shop과 Inventory의 UI 작업 및 Trade 최종 검수 결과 | 어떤 일을 마쳤는지 |
| Option UI 호출 미구현 | 무엇이 남았는지 |

이름은 전보다 읽기 쉬워졌지만 파일이 잘게 나뉘어 찾기 어려운 점은 남아 있습니다.
