# AI 활용 자료 수집과 적용 검토

AI 사용법과 기술 자료를 모아 두려고 Hub라는 개인 작업 공간을 만들었습니다. 관심 있는 링크를 제공하고 관련 지식을 더 찾아보도록 요청했습니다. 당장 쓰기 어려운 자료도 버리지 않고 보관해 나중에 다시 검토할 수 있게 했습니다.

## 제가 정한 적용 기준

자료 수집 방향과 적용 기준은 제가 정했습니다. 세부 조사와 비교, 코드 변경은 AI가 맡았습니다.

| 적용 기준 | 확인하려던 내용 |
| --- | --- |
| 내 컴퓨터에서 실행할 수 있는가 | 현재 환경과 메모리 조건에서 사용할 수 있는지 |
| 평소 하는 작업에 필요한가 | 문서 검색이나 문자 인식처럼 실제 작업에 도움이 되는지 |

[자료를 보관하고 다시 검토하기 위한 분류](evidence/library-excerpt.md)

## AI가 수행한 검색 보완 사례

다음 작업을 찾는 검색에서 현재 안내보다 과거 설계 문서가 먼저 나오는 문제가 있었습니다. AI가 검색 결과를 비교하고 현재 안내에 별칭 두 개를 추가했습니다.

기존 고정 검사 65개 중 통과한 항목은 수정 전 64개에서 수정 후 65개로 늘었습니다.
