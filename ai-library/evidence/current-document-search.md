# 현재 안내를 찾는 검색 경로 보완

2026년 9월 13일 Hub 검색 비교와 수정 기록입니다. 비교와 코드 변경은 AI가 수행했습니다.

`hub 다음 작업`이라는 질의에서 현재 안내보다 과거 설계 문서가 먼저 검색됐습니다. 현재 안내의 별칭에 해당 표현이 없어 본문 검색 순위에 맡겨졌던 상황이었습니다.

현재 안내에 한국어와 혼합 표기 별칭 두 개를 추가했습니다. 기존 고정 검사 65개는 수정 전 64개 통과에서 수정 후 65개 통과로 바뀌었습니다.

이와 함께 대기와 다음 작업, 승인 상태는 검색 순위에 맡기지 않고 현재 작업 기록을 직접 확인하도록 안내했습니다.
