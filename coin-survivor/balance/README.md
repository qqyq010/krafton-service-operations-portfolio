# 비용 조정표와 밸런스 시트

[Excel 파일](balance.xlsx)

구매와 가방 확장 비용, 성장 흐름을 비교한 계산표입니다. 2026년 7월 16일 코드와 데이터를 기준으로 작성됐고 전투 수치와 플레이 측정 양식도 들어 있습니다. AI가 영상과 코드의 수치를 검토하고 표를 작성했습니다.

[초반 비용 부담과 재플레이 경험](../cases/shop-and-bag-costs.md)

## 시트에 들어 있는 내용

| 구성 | 내용 |
| --- | --- |
| 대시보드 | 구매와 확장 문제 및 조정 목표 |
| 현재 기준 | 2026년 7월 16일 기준값과 출처 |
| 성장 곡선 | 누적 획득 목표와 상점 진입비 및 잔액 계산 |
| 스폰 타임라인 | 시간별 적 유지 목표와 근거리 및 원거리 구성 |
| 적과 보스 | 체력과 피해, 보상 및 출현 시각 |
| 경제 흐름 | 구간별 성장 목표와 상점 이용 후 남는 골드 |
| 인벤토리 경제 | 확장비와 합성 원가, 판매 회수율 및 점유 칸 |
| 패시브 시너지 | 등급별 효과와 발동 조건 및 조합별 확인 항목 |
| 무기 DPS | 무기 비교 계산과 실제 피해량 입력란 |
| 성장과 카메라 예산 | 몸집과 카메라 배율 및 상점 전후 상태 |
| 플레이 모드 입력 | 시간별 측정값과 구간 판정 및 수정 후 확인 양식 |
| 데이터 품질 | 출처와 확인 방법 |

## 계산값과 측정값

노란 칸은 실제 플레이 측정값을 넣는 곳이며 현재는 비어 있습니다. 플레이 모드 입력은 필수 숫자 6개가 모두 들어와야 구간을 판정하며 빠진 값이 있으면 미측정으로 표시합니다.

제가 조정 후 다시 플레이했을 때는 상점과 거래 구간이 전보다 수월하게 느껴졌습니다. 이 재플레이가 어느 조정 버전이었는지는 확인하지 못했습니다.
