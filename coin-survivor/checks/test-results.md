# 무기 판매 수정 후 테스트

2026년 5월 12일  /  Unity 에디터 Play Mode

판매한 무기의 공격이 멈추는지 확인한 뒤 구매와 합성도 이어서 테스트했습니다.

| 테스트 | 당시 확인한 결과 |
|---|---|
| 2레벨 무기 판매 | 판매한 레벨의 무기만 제거됨 |
| 같은 종류의 1레벨 / 2레벨을 함께 둔 상태에서 2레벨 판매 | 1레벨은 그대로 유지 |
| 판매 확정 / 취소 | 정상 동작 |
| 가방에 빈칸이 있을 때 1레벨 무기 구매 | 실제 전투에 무기 장착 |
| 가방이 가득 찬 상태에서 같은 1레벨 무기 구매 | 자동 합성 후 2레벨 무기로 교체 |
| 같은 1레벨 무기가 여러 개 있을 때 자동 합성 | 하나만 2레벨로 변경되고 나머지는 유지 |
| 수동 무기 합성 | 정상 동작 |
| 패시브 아이템 구매 / 판매 / 합성 | 정상 동작 |
| Unity 콘솔 | 새 오류 / 경고 없음 |

방어구는 테스트할 아이템이 없어 확인하지 못했습니다.
