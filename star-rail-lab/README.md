# Star Rail Lab

붕괴 스타레일을 플레이하며 보유 캐릭터와 장비를 바탕으로 파티 구성과 육성 방향을 비교하고 싶어 시작한 개인 프로젝트입니다.
현재 포트폴리오에서는 **계정 연결 없이 조건을 지정하고 실제 로컬 API의 계산 결과와 제한을 확인하는 비교 실험실**을 보여 줍니다.

[화면으로 사용 흐름 보기](workflow.md) / [입력과 결과 처리 사례](cases/input-and-result-validation.md) / [코드 발췌](code/README.md)

## 만든 흐름

1. 캐릭터와 장비 비교, 파티 관계 비교, 조건별 효과 비교 중 목적을 선택합니다.
2. 캐릭터와 장비 또는 파티원, 발동 조건, 비교할 목표값을 직접 지정합니다.
3. 같은 기준으로 계산한 A와 B의 차이, 목표 충족 여부, 연결 근거와 미지원 이유를 봅니다.

입력 변경 시 이전 결과를 지우고 같은 인물을 중복 선택한 파티는 거부합니다.
비교 탭을 이동하면 같은 비교의 입력과 결과를 유지합니다.

## 본인과 AI의 기여

| 주체 | 역할 |
| --- | --- |
| 차선호 | 사용 목적과 필요한 기능 제시, 실제 게임의 Scanner 오류 재현과 기록 전달, 결과 확인 기준과 수정 방향 제시 |
| AI 도구 Codex | 코드 분석과 수정, 비교 화면 구성, 자동 검사와 브라우저 조작, 캡처 및 문서 작성 |
| 기존 오픈소스 | 계정 수집 영역은 HSR-Scanner를 바탕으로 연동과 수정을 진행. 원본 스캐너 개발 성과와 구분 |

프로그래밍 구현 전체를 혼자 작성한 경험으로 기재하지 않습니다.
이 자료에서 본인의 기여는 필요한 기능과 문제를 정하고 실제 실행에서 드러난 불편을 전달하며, 수정 결과를 판단할 기준을 요구한 부분입니다.

## 기술과 결과물

- React UI와 FastAPI 기반 로컬 API
- 고정 DB와 지정한 가정에 따른 비교
- 2560 x 1440 실제 앱 화면 5장
- 입력 검증과 이전 결과 제거, 중복 파티 거부를 보여 주는 코드 발췌

## 현재 확인 범위

2026년 10월 20일 기록에서 실제 HTTP 계산, 비교 탭 유지, 입력 변경 후 결과 제거, 중복 파티 거부를 브라우저로 확인했습니다.
이 캡처에 개인 계정 기록을 사용하지 않았습니다. 계산 자료는 고정 후보 DB 4.6.0이며 최신 게임 전체를 지원한다는 의미는 아닙니다.
전체 계정 스캔, 실제 장비를 반영한 최적화, 자동 전투와 실전 성능 검증은 남아 있습니다.

## 공개 자료의 구성

이 저장소에는 선별한 화면과 코드, 검증 요약을 담았습니다.
원본 게임 DB, 계정 스냅샷, 실행 토큰과 원본 진단 파일은 포함하지 않습니다.
코드는 원 프로젝트 발췌이며 일부 의존 파일이 빠져 있어 단독 실행되지 않습니다.
