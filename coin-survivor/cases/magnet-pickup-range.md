# 자석을 써도 획득 범위 차이가 작았던 문제

아이템 획득 효과 / 2026년 7월

자석을 사용했는데도 아이템을 줍는 범위가 거의 달라지지 않았습니다. 이 상황을 전달하고 코드 분석과 수정에 참여했습니다. 7월 16일 다시 플레이했을 때는 아이템을 줍는 범위가 넓어진 것을 확인했습니다.

## 첨부 코드

[획득 반경 계산](../code/magnet-pickup-range.cs)은 기본 반경에 로비 업그레이드 배율을 곱하는 부분입니다. 자석 패시브의 수정 코드 전체를 담은 파일은 아닙니다.

공격 범위가 너무 넓었던 문제는 [진화 무기 조정](evolved-weapon-balance.md)에서 다룹니다.
